Penyedia LLM (fallback berurutan)

Untuk menerjemahkan, sistem menelusuri model dari provider paling atas ke bawah. Model pertama yang merespons valid dipakai; kuota habis/gagal → pindah otomatis. Isi Base URL + API Key → daftar model diambil otomatis, tinggal pilih.

Penyimpanan & keamanan konfigurasi

• Tersimpan di config/providers.json — ditulis atomik (tidak bisa setengah-tertulis saat listrik/server mati) + backup otomatis versi sebelumnya di providers.json.bak.
• Kalau file terlanjur korup, sistem otomatis mencoba memulihkan dari .bak; file korup tidak pernah ditimpa diam-diam.
• Izin file 600 — hanya pemilik proses yang bisa membacanya.
• API key tidak pernah ditampilkan ulang di UI (kolom kosong = pakai key tersimpan).
• Di Docker, folder config/ di-mount sebagai volume → konfigurasi aman saat image di-rebuild.

Catatan

• openai = endpoint OpenAI-compatible (/v1/chat/completions): router bawaan, LiteLLM, OpenRouter, vLLM, Ollama, Groq, dll.
• gemini = Google Gemini API (generativelanguage.googleapis.com/v1beta).
• Provider bawaan tanpa key → otomatis pakai key dari ~/.hermes/.env.
• Vision model per provider dipakai khusus untuk request bergambar (Vision OCR). Kosongkan jika model utama sudah multimodal.
• Untuk gemini, hanya model yang mendukung generateContent yang ditampilkan.
